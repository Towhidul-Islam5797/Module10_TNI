MILESTONE 3 - INVENTORY BASICS: PLAN
Project: Module10_TNI (Unity 6.3 LTS, URP, Input System)
Scene: ThirdPerson only (FirstPerson is out of scope)
Date: 31 Oct 2026

==================================================================
GOAL
==================================================================
The player can walk up to items in the world, press E to pick them up,
see them in a hotbar at the bottom of the screen, pick a slot with the
number keys 1-6, and press Q to use the selected item.
A Health Potion heals the player and the green health bar goes up.

Ideas the students learn:
- Item data stored in a ScriptableObject asset
- An inventory as a list of slots (item + count)
- Stacking (fill existing stacks first, then empty slots)
- Picking items up through the existing IInteractable system
- Showing the inventory on screen (hotbar UI)
- Selecting and using an item

==================================================================
HOW WE BUILD AND TEST (every sprint)
==================================================================
- New objects in the scene and new assets are made by an Editor script,
  Assets/Editor/InventorySceneSetup.cs (menu Tools/Setup Inventory Scene).
  It is safe to run twice: it replaces what it made before.
- Assets/Editor/InventoryValidation.cs (menu Tools/Validate Inventory) checks
  the code and the scene without Play mode and prints [PASS] / [FAIL].
- Both are run in batchmode. A sprint is done when the compile log has zero
  "error CS" lines and the validation log has zero [FAIL] lines.
- The teacher then runs the manual Play-mode test list from the SprintDoc.
