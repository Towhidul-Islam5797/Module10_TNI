SPRINT 2 - PUNCH AND KICK COMBOS WITH RAYCAST DAMAGE (ThirdPerson scene)
Milestone 2: Combat

GOAL
Left click: punch combo (Punch -> Boxing -> ElbowPunch -> loop). The player can walk and run while punching.
Right click: kick combo (FrontKick -> Kicking -> loop). The player stops while kicking.
Every click fires a raycast forward and damages the enemy it hits.

HOW IT WORKS
1. Two Animator layers run at the same time. The Base Layer drives the whole body (run, jump, kicks).
2. The UpperBody layer sits on top. Its mask only lets it control the upper body.
   While it is in Empty it does nothing, so the Base Layer shows through.
3. A punch moves the UpperBody layer into Punch. The arms punch, the legs keep running from the Base Layer.
4. Kicks need the legs, so they live in the Base Layer and the player stops moving.
5. Chains: a click during a move sets the trigger again. At Exit Time 0.5 the next move starts.
   No click: the move ends at Exit Time 0.9 and goes back to Empty or Locomotion.

DONE CONDITIONS
- Left click while running: arms punch, legs keep running.
- Repeated left clicks chain Punch, Boxing, ElbowPunch.
- Right click: player stops and kicks. Repeated right clicks chain FrontKick, Kicking.
- Facing the enemy within 1.5 m, each click prints "Enemy took X damage. Health: Y" (10 punch, 20 kick).
- Scene view shows the ray for 1 second: green on hit, red on miss.

KNOWN ISSUES
- Damage lands on the click, before the fist or foot visibly connects.
- Jump is not blocked while kicking.
- A trigger set during a jump fires on landing.
- If the arms snap to a T-pose when not punching, select the Empty state in the UpperBody layer and turn off Write Defaults.
